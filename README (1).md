# 안녕하세요 — 인공지능에 관심 있는 학생입니다

대덕소프트웨어 마이스터고등학교에 재학 중인 학생입니다. 인공지능(AI)과 머신러닝, 딥러닝에 큰 관심을 가지고 있으며, Python과 Unity를 사용해 실습하고 프로젝트를 만들어가고 있습니다.

## 관심 분야

- 머신러닝 / 딥러닝
- 컴퓨터 비전 (이미지 분류, 객체 인식)
- 자연어 처리 (NLP)
- 강화학습 및 시뮬레이션

## 진행 중인 프로젝트

- Unity + Python을 이용한 실습 프로젝트
- 간단한 딥러닝 모델 구현 (TensorFlow / PyTorch 연습)

프로젝트별로 폴더를 만들고 간단한 설명과 실행 방법을 함께 올립니다. 관심 있는 프로젝트가 있으면 언제든지 열어보세요.

## 기술 스택

- 프로그래밍: Python, C#(Unity)
- 라이브러리: NumPy, pandas, TensorFlow, PyTorch, OpenCV
- 도구: Git, GitHub, VS Code, Unity

## 실행 예시

프로젝트 루트에 `requirements.txt`가 있으면 다음 명령으로 의존성을 설치할 수 있습니다:

```
pip install -r requirements.txt
```

프로젝트 실행 방법은 각 프로젝트의 README를 참고하세요.
